Unicode Cleaner

Görünməyən və qeyri-adi Unicode simvollarını aşkarlayın, yerlərini görün və mətni təhlükəsiz şəkildə təmizləyin.

🔒 Mətn brauzerdən çıxmır

1. Mətni daxil edin

Mətni yapışdırın və “Analiz et” düyməsini seçin.

0 simvol

2. Təmizləmə rejimi

Mətnin necə təmizlənəcəyini seçin.

Aşkarlanan şübhəli simvollar 0
Fərqli Unicode növləri 0
Təmizləmədən sonra dəyişiklik 0

3. Aşkarlanan simvollar

Unicode kodu, adı, sayı və mətndəki mövqeləri göstərilir.

Unicode Ad Kateqoriya Say Mövqelər Əməl
Hələ analiz aparılmayıb.

4. Vizual görünüş

Görünməyən simvollar mətndə ⟦U+XXXX⟧ formatında göstərilir.

Analiz nəticəsi burada görünəcək.

5. Təmizlənmiş mətn

Seçilmiş rejimə uyğun nəticə.

Vacib qeyd: Görünməyən Unicode simvollarının mövcudluğu mətnin süni intellekt tərəfindən yaradıldığını sübut etmir. Bu alət yalnız qeyri-adi və görünməyən Unicode simvollarını texniki baxımdan aşkarlayır və təmizləyir.
